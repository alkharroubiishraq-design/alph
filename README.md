# The Football Phonics Academy — صفحة الهبوط

صفحة هبوط جاهزة لتحميل دوسية "The Football Phonics Academy" مجاناً.

## طريقة النشر على GitHub Pages (خطوة بخطوة)

1. روحي على [github.com](https://github.com) وسجّلي دخول (أو أنشئي حساب مجاني).
2. اضغطي على **+** بأعلى الصفحة > **New repository**.
3. سمّيها مثلاً `football-phonics-academy` واختاري **Public** ثم **Create repository**.
4. بصفحة الريبو الفاضية، اضغطي **uploading an existing file**.
5. اسحبي وأفلتي **كل الملفات** (`index.html` ومجلد `assets` بكامله) بمكان الرفع.
   - إذا ما قبل رفع مجلد كامل بالسحب والإفلات، ارفعي أول `index.html`، وبعدين ادخلي على الريبو واعملي مجلد `assets` وارفعي كل الملفات اللي جواه واحد واحد (أو استخدمي GitHub Desktop لتسهيل الموضوع).
6. اكتبي رسالة أي شي بخانة الـ commit واضغطي **Commit changes**.
7. روحي على **Settings** (بأعلى الريبو) > **Pages** من القائمة الجانبية.
8. تحت **Build and deployment > Source** اختاري **Deploy from a branch**، وتحت **Branch** اختاري `main` والمجلد `/ (root)`، ثم **Save**.
9. استنّي دقيقة أو دقيقتين، ورح يظهرلك رابط الصفحة بأعلى نفس الإعدادات، شكله تقريباً:
   `https://USERNAME.github.io/football-phonics-academy/`

هاد الرابط هو رابط صفحة الهبوط الجاهزة للمشاركة مع أي أهل أو معلم — زر التحميل رح يشتغل مباشرة من نفس الرابط.

## بنية الملفات

```
index.html                 ← الصفحة نفسها
assets/
  Football-Phonics-Academy-Workbook.pdf   ← ملف الدوسية (٩٣ صفحة)
  cover.jpg, letter-*.jpg   ← صور المعاينة داخل الصفحة
```
